## Featured Projects

### TripWise: Full-Stack Travel Planner
[Live Demo](https://trip-wise-psi.vercel.app/) · [Source Code](https://github.com/patilkaivalya/TripWise)

A responsive travel-planning web app that brings flight search, hotels, budgeting and itinerary building into one place.

- Location autocomplete, outbound and return flight search, hotel listings and pricing, and nearby restaurant and attraction discovery
- Trip selection, budget estimation, day-by-day itinerary generation and browser-based PDF export
- Handles loading, empty and error states across all search workflows

**Stack:** React.js · Vite · Tailwind CSS · Python · Flask · SerpApi

### AI Customer Support Copilot
An AI-assisted support platform that helps agents resolve customer queries faster.

- React agent dashboard with a FastAPI backend and MySQL data models for customers, tickets, conversation history and orders
- JWT authentication and REST APIs for customer and order information retrieval
- LLM integration with a context-retrieval workflow that drafts replies for agent review

**Stack:** React.js · Python · FastAPI · MySQL · JWT · LLM APIs

### Nearby Medicine Finder
A location-aware web app that helps users find nearby pharmacies stocking a medicine.

- Store discovery with OpenStreetMap and Nominatim geocoding and distance-based filtering
- Store-owner registration, multi-store management and PDF export of medicine lists
- Flask REST backend with a relational SQLite schema

**Stack:** Python · Flask · SQLite · JavaScript · HTML · CSS · OpenStreetMap
